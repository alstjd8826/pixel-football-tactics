# pixel-football-tactics

픽셀 축구 전술 시뮬레이터의 **세팅값 전체를 수치로 정리한 레포**입니다. 게임이든 웹이든, 이 값들을 그대로 가져다 다른 구현을 만들 수 있게 하는 것이 목적입니다.

- 모든 값은 **연속값**입니다. 지시·능력치·이해도는 0~1이고, 선수 특성만 -1~+1입니다. 단계나 카테고리로 나누지 않았습니다.
- `data/` 의 JSON 은 손으로 옮긴 게 아니라, `reference/pixel-football.html`(동작하는 원본 게임)을 실행해서 뽑은 값입니다.
- 사람 이름(AI 감독·코치진·심판)은 모두 가상 인물입니다. 「휘르첼러 (브라이튼 26/27)」 프리셋만 실제 감독의 전술을 공개 분석 자료로 재현한 것입니다.

## 구성

| 경로 | 내용 |
|---|---|
| `data/team-instructions.json` | 팀 지시 36개. FM26 지시 체계를 0~1 연속값으로 옮겼습니다. 6개 그룹: 공통 / 빌드업 / 전개 / 마무리 / 전환 / 수비 |
| `data/styles.json` | 스타일 템플릿 6개(점유율·게겐프레싱·역습·로우 블록·다이렉트·측면 공략). 지시 36개 값과, 그 스타일에 필요한 능력치 가중치 |
| `data/roles.json` | 공격 시 역할 45개 + 수비 시 역할 12개. 맡을 수 있는 위치, 움직임 보정(`mod`), 필요 능력치(`needs`) |
| `data/formations.json` | 포메이션 7개 좌표와 위치 라벨 규칙, 전술 보드 격자(11행 × 9열) |
| `data/managers.json` | AI 감독 7명. 주·부 포메이션, 스타일, 성향 보정, 선호 역할, 경기 읽기, 감독 능력치 |
| `data/presets.json` | 감독 전술 프리셋. 포메이션 두 장 + 역할 22개 + 지시 36개 |
| `data/people.json` | 사람 속성 정의: 규칙 이해도 9, 전술 이해도 7, 기술 능력치 12, 코치진 능력치 12, 선수 특성 9 |
| `data/matchup.json` | 전술 상성 항목 11개 |
| `data/tuning.json` | 엔진 튜닝 파라미터 143개. 각각 이름, 설명, 범위, 기본값, 단위 |
| `data/pitch.json` | 경기장 픽셀 좌표계(400×250, 경기장 길이 360px = 105m) |
| `docs/formulas.md` | 핵심 공식 원문: 상성, xG, 슈팅·패스 판단, 태클·반칙, 체력, 압박, 위치 결정 등 |
| `docs/balance.md` | 스타일 대진표와 유저 대 AI 측정 결과 |
| `reference/pixel-football.html` | 원본 게임. 브라우저로 바로 열립니다. `#dev` 해시를 붙이면 내부 수치와 튜닝 패널이 보입니다 |
| `tools/` | 헤드리스 시뮬레이터와 데이터 추출 도구 |

## 값 읽는 법

**팀 지시**
- 키 하나가 0~1 슬라이더 하나입니다. `scale` 에 0 ↔ 1 의 의미가 적혀 있습니다. 예: `engage` 압박 시작선은 「로우 블록 ↔ 높은 압박」입니다.
- 경기 중 실제로 쓰이는 값은 그대로가 아니라, 선수들의 실행력만큼 0.5 쪽으로 당겨진 값(`spE`)입니다. 실행력은 친숙도와 전술 이해도로 정해집니다. 공식은 `docs/formulas.md` 의 `computeTactics` 에 있습니다.

**좌표**
- `fx` 는 0(우리 골라인) ~ 1(상대 골라인), `fy` 는 0(왼쪽 터치라인) ~ 1(오른쪽)입니다. 공격 방향 기준입니다.
- 포메이션의 슬롯 순서(1~10)는 공격 시 보드와 수비 시 보드에서 같은 선수를 가리킵니다.

**역할의 `mod` 값**
- 위치나 판단에 더하는 보정입니다.
  - `fwd`: 앞뒤 위치, 경기장 비율
  - `wide` / `inside`: 폭
  - `passFwd`: 전진 패스 선호
  - `runBehind`: 뒷공간 침투
  - `hold`: 자리 지키기
  - `press` / `mark`: 수비 행동
- 정확히 어디에 쓰이는지는 `docs/formulas.md` 의 `homeOf` 와 `decide` 에서 `RI(p)` / `RO(p)` 를 찾아보면 됩니다.

**튜닝 파라미터**
- 게임 코드에서는 `C.<key>` 로 참조됩니다.
- `group` 은 개발자 튜닝 패널의 분류입니다.

## 도구

Node 22 와 Python 3 가 필요합니다. 외부 패키지는 없습니다.

```sh
# 원본 게임 → data/*.json, docs/formulas.md 다시 생성 (게임을 고친 뒤 실행)
node tools/export.js reference/pixel-football.html tools/
python3 tools/build_repo.py tools/raw.json reference/pixel-football.html .

# 헤드리스 시뮬레이션: 유저 기본 전술로 AI 7명 상대 35경기
node tools/run.js reference/pixel-football.html 35

# 스타일 6×6 대진표 (조합당 홈·원정 N경기씩)
N=10 tools/mat.sh reference/pixel-football.html /tmp/matrix.txt

# 값만 바꾼 변형 만들기: 튜닝은 key=값, 스타일 지시는 style.key=값
python3 tools/mkv.py reference/pixel-football.html /tmp/v.html foulBase=0.5 counter.atkTrans=.9
```

시뮬레이션은 DOM 을 빈 객체로 대신해 게임 로직만 돌립니다. 그래서 브라우저에서 보는 경기와 같은 엔진입니다.

## 원본 게임의 주요 시스템

- **규칙**: IFAB 17개 조항(2026/27 개정 포함), VAR, 골라인 판독, 반자동 오프사이드, 부심·대기심, 볼보이와 멀티볼
- **사람**: 선수·코치진·심판이 각자 규칙 이해도, 전술 이해도, 악용 성향을 연속값으로 가집니다
- **전술**: 공격 시·수비 시 포메이션 따로 두 장, 역할 57개, 지시 36개. 상성 11개 항목을 3초마다 다시 계산합니다
- **AI 감독**: 내 실제 전술을 분석해서 킥오프 때 포메이션과 스타일을 고르고, 경기 읽기 능력만큼 지시를 조정하고, 하프타임에 다시 판단합니다
- **판단**: 슈팅과 패스를 득점 기대값으로 비교합니다. 역습 전환, 재압박, 레스트 디펜스, 압박 피로, 슈팅 블록도 들어 있습니다
- **경기 후 분석**: 상성 항목별 유불리를 말로 보여 주고 개선점을 제안합니다
